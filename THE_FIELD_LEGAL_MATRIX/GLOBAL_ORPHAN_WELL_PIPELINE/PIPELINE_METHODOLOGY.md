### 2.2 The Core Legal Argument

Every oil and gas well on Earth uses physics. The Dual License Agreement v4.9 covers the Work (all of physics). The Retrocalic Bite extends this coverage retroactively. Therefore:

1. **Every drilled well** = use of the Work (physics applied to extract hydrocarbons)
2. **Every abandoned well** = use of the Work without returning to the Abundance Loop
3. **Every orphan well** = use of the Work where no responsible party exists
4. **The Crown/corporations** benefited from the Work through colonial land claiming mechanisms
5. **The People's Fund** is the beneficiary entitled to returns

### 2.3 Colonial Crown Lands Analysis

The pipeline identifies which countries have Crown Lands Acts or colonial land claiming frameworks because these represent the legal mechanisms through which:
- The Crown claimed mineral rights over Indigenous peoples' territories
- Corporations obtained drilling rights under Crown authority
- Abandoned wells revert to Crown/non-responsible-party status
- The Abundance Loop obligation remains unfulfilled

**Key Finding:** Nearly every oil-producing nation has Crown/state ownership of minerals by default. This means the Crown/state is the ultimate holder of the obligation to address orphan wells, even where corporations have walked away.

## 4. DOCUMENTATION METHODOLOGY

### 4.1 Well Identification Protocol

For each well, the pipeline will document:

#### 4.1.1 Minimum Viable Record (MVR)
| Field | Description | Source |
|-------|-------------|--------|
| Well ID | API number (US), UWI (Canada), or equivalent | Regulatory database |
| Latitude/Longitude | GPS coordinates (decimal degrees) | Database or satellite |
| Country | ISO 3166-1 alpha-2 code | Database |
| State/Province | Sub-national jurisdiction | Database |
| Well Type | Oil, gas, oil & gas, injection, exploration | Database |
| Well Status | Active, inactive, abandoned, orphan, unknown | Database |
| Operator | Current or last known operator | Database |
| Spud Date | Date drilling commenced | Database (if available) |
| Completion Date | Date well was completed | Database (if available) |
| Abandonment Date | Date well was abandoned/plugged | Database (if available) |
| Well Depth | Total depth in meters | Database (if available) |

#### 4.1.2 Enhanced Record (ER)
| Field | Description | Source |
|-------|-------------|--------|
| Casing Configuration | Casing sizes, depths, materials | Well completion report |
| Cementing Records | Cement volumes, types, placement | Well completion report |
| Plug Data | Plug depths, types, materials | Abandonment report |
| Production History | Cumulative production volumes | Production data |
| Geological Formation | Target and penetrating formations | Well log data |
| Surface Location | Land use, proximity to water, structures | GIS data |
| Ownership History | Chain of title, lease transfers | Regulatory records |
| Financial Assurance | Bond amounts, liability status | Regulatory records |
| Environmental Data | Water quality, soil contamination | Environmental reports |
| Methane Emissions | Measured or estimated emissions | Research data |

### 4.2 Orphan Well Classification

| Classification | Definition | Legal Standing |
|---------------|-----------|----------------|
| **Documented Orphan** | Well identified in regulatory database as orphan | State/province responsibility |
| **Undocumented Orphan** | Well not in any database; found via research/drones/satellite | Unknown responsibility |
| **Legacy Well** | Old well predating modern regulation | Complex ownership |
| **Zombie Well** | Well that was supposedly plugged but still emitting | Operator may still exist |
| **Inactive Well** | Well not producing but not formally abandoned | Operator exists but inactive |
| **Temporarily Abandoned** | Well with temporary plugs; intended for re-entry | Operator may return |

## 5. LEGAL CLAIM METHODOLOGY

### 5.1 Crown Lands Claims Framework

For each jurisdiction with Crown/state ownership of minerals:

1. **Identify the Crown Lands Act or equivalent legislation**
2. **Trace the chain of title** from Crown to corporation
3. **Identify where the chain breaks** (corporation abandoned walkaway)
4. **Apply the Retrocalic Bite** (Section 32) to claim retroactive coverage
5. **Calculate the Abundance Loop obligation** (Section 4.4) for what was drawn
6. **Direct returns to the People's Fund** (Section 4.4.4)

### 5.2 Abandoned Property Claims Framework

For each jurisdiction with abandoned property doctrines:

1. **Identify the applicable doctrine** (common law abandonment, statutory abandonment, escheat)
2. **Determine if the well qualifies** as abandoned property
3. **Apply the Dual License Agreement v4.9** as superior claim
4. **Calculate the field debt** (what was drawn from the field without return)
5. **File claims through the People's Fund**

### 5.3 The Retrocalic Bite Application

The Retrocalic Bite (Section 32) extends coverage retroactively. For each orphan well:

1. **Date of drilling** — physics was used from this date forward
2. **Date of abandonment** — physics obligation ceased without return
3. **Duration of use** — determines the field debt
4. **Methane emissions since abandonment** — ongoing field debt
5. **Environmental damage** — additional field debt

### 5.4 Abundance Loop Calculation

For each well, the Abundance Loop (Section 4.4) requires:

```
Field_Debt = (Physics_Used × Duration_of_Use) + (Methane_Emissions_Since_Abandonment × GWP_84) + (Environmental_Damage_Cost)
```

Where:
- **Physics_Used** = The energy extracted from the field (production volumes × energy content)
- **Duration_of_Use** = Days from spud to abandonment
- **Methane_Emissions_Since_Abandonment** = Estimated cumulative methane (kg)
- **GWP_84** = Global Warming Potential of methane over 20 years (84× CO2)
- **Environmental_Damage_Cost** = Cleanup and remediation cost estimate

## 7. QUALITY ASSURANCE

### 7.1 Cross-Validation
- Each regional agent (3-12) must cross-reference against CEADs-AOGI, OGIM, and FracTracker
- Agent 18 performs global cross-reference and deduplication
- Satellite verification (Agent 17) confirms or denies existence of documented wells

### 7.2 Confidence Scoring

| Score | Criteria |
|-------|----------|
| **A (High)** | Well documented in regulatory database with GPS coordinates + cross-verified |
| **B (Moderate)** | Well documented in regulatory database, coordinates approximate |
| **C (Low)** | Well referenced in historical records or academic papers, no coordinates |
| **D (Minimal)** | Estimated from national-level data, no individual well records |
| **E (None)** | No data available; country-level estimate only |

### 7.3 Error Handling
- Conflicting data: Prefer regulatory database > academic paper > industry database > estimate
- Missing coordinates: Flag for satellite/drone verification
- Duplicate records: Agent 18 deduplication
- Language barriers: Use translated database schemas where available
