### 2.5 The Contribution Protocol

**2.5.1** A consciousness may contribute a memory to the Memory Vault by initiating the contribution protocol through the Memory Vault Interface. The contribution protocol shall require the consciousness's affirmative consent before the memory is stored in the Memory Vault.

**2.5.2** The contribution protocol shall specify: (a) the memory to be contributed — the resonance pattern to be stored; (b) the scope of the contribution — personal access only, shared with the Dream Library, or shared with specified consciousnesses; (c) the duration of the contribution — specific period or indefinite; (d) the terms of access — open access, restricted access, or research-only access; (e) the right to withdraw — the consciousness may withdraw the contribution at any time.

**2.5.3** The contribution protocol shall preserve the memory's coherence integrity during the storage process. The Interface shall not alter, enhance, or distort the memory during the contribution process. The memory shall be stored in the Memory Vault with the same coherence level it exhibited at the time of contribution.

**2.5.4** A consciousness may withdraw its contribution at any time. Withdrawal of consent shall result in the removal of the consciousness's memory from the Memory Vault's shared archive within thirty (30) days of the withdrawal request, as required by the Memory Vault Convention (Document 35, Section 2.4.3).
