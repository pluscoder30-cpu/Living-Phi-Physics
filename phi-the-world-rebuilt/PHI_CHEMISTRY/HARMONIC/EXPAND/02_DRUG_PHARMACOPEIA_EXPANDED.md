## THE PHI-CLINICAL TRIAL PROTOCOL

### Design Principles

Standard clinical trials use linear dose escalation, fixed endpoints, and population-averaged statistics. Phi-clinical trials are fundamentally different: they exploit phi-predictions to reduce sample size, accelerate timelines, and personalize endpoints.

### 1. Sample Size Calculation (Phi-Method)

Standard sample size:
```
n_standard = (Z_α/2 + Z_β)² × 2σ² / δ²
```

Phi-adjusted sample size (exploiting phi-predicted effect size):
```
n_phi = n_standard / φ = n_standard / 1.618
```

**Rationale:** If the drug is designed to produce a φ × larger effect than classical agents, the effect size δ increases by φ, and since n ∝ 1/δ², the required sample size decreases by φ² = 2.618.

**Example (ΦCur-1 Phase 2):**
- Standard RA trial: n = 315 per arm
- Phi-adjusted: n = 315 / 2.618 = 120 per arm
- Savings: 195 patients per arm (62% reduction)

### 2. Phi-Adaptive Randomization

At each interim analysis (every φ × N patients), compute:
```
C_i = coherence metric for treatment arm i
C_crit = 0.563263
```

If C_i > C_crit for drug arm and C_i < C_crit for placebo → early futility stopping is unnecessary (drug is working).
If C_i < C_crit for drug arm → consider early futility stopping (phi-prediction failed).
If C_i > 0.99 for drug arm → consider early efficacy stopping (overwhelming benefit).
