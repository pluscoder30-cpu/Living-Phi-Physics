# CLOTHING IN A COLLAPSE

When the system goes down, what you wear keeps you alive. Clothes protect you from sun, rain, wind, cold, heat, and sharp objects. This guide shows you what to wear, how to make simple clothes, and how to fix what you have.

---

## What to Wear

### The 3-Layer Rule

Always wear at least 3 layers. Each layer does a different job:

```
LAYER SYSTEM
============

  LAYER 3: SHELL (outer)
  ┌─────────────────────┐
  │ Wind/rain protection │
  │ Blocks elements      │
  └─────────┬───────────┘
            │
  LAYER 2: INSULATION (middle)
  ┌─────────────────────┐
  │ Traps body heat      │
  │ Keeps you warm       │
  └─────────┬───────────┘
            │
  LAYER 1: BASE (inner)
  ┌─────────────────────┐
  │ Wicks sweat away     │
  │ Touches your skin    │
  └─────────────────────┘

  ADD OR REMOVE LAYERS
  TO CONTROL YOUR HEAT
```

### Fiber Rules

| Fiber | Good For | Bad For |
|-------|----------|---------|
| **Cotton** | Base layer, warm weather | Stays wet, loses warmth |
| **Wool** | Insulation, rain | Itchy if not soft |
| **Linen** | Hot weather, base layer | Tears easily |
| **Leather** | Shell, shoes, gloves | Heavy, needs care |
| **Synthetic** | Shell (rain gear) | MELTS near fire |

**Critical rule:** Never wear synthetic fabric near fire. It melts to your skin.

### Essential Clothing Items

- **Head covering** — sun protection, heat retention, rain shield
- **Sturdy shoes** — protect feet from cuts, thorns, rocks
- **Long pants** — leg protection from bugs, thorns, sun
- **Long sleeve shirt** — arm protection, sun shield
- **Jacket or vest** — warmth layer

## How to Make Simple Clothes

### Poncho from a Tarp

The easiest clothing to make. Keeps rain off your whole body.

```
PONCHO CONSTRUCTION
====================

  Step 1: Get a tarp or large cloth
  ┌───────────────────────────┐
  │                           │
  │                           │
  │                           │
  │                           │
  │                           │
  └───────────────────────────┘

  Step 2: Cut a hole for your head (center)
  ┌───────────────────────────┐
  │                           │
  │         ┌─────┐           │
  │         │HEAD │           │
  │         └─────┘           │
  │                           │
  │                           │
  └───────────────────────────┘

  Step 3: Tie sides together (leave arm holes)
  ┌───────────────────────────┐
  │            ▲              │
  │           ╱│╲             │
  │    ┌─────┘ │ └─────┐      │
  │    │HEAD   │       │      │
  │    └───────┼───────┘      │
  │    ╱       │       ╲      │
  │   TIE      │      TIE    │
  │            │              │
  └───────────────────────────┘

  Step 4: You now have rain protection!
  - Wear over any clothing
  - Arms come out the side holes
  - Covers your back, chest, and legs
```

### Vest from an Old Shirt

Turn a damaged shirt into a useful vest.

```
VEST FROM SHIRT
===============

  Original shirt:        Vest:
  ┌──────────┐          ┌──────────┐
  │  ┌────┐  │          │          │
  │  │HEAD│  │          │  ┌────┐  │
  │  └────┘  │   CUT    │  │HEAD│  │
  │ /        \   ───►   │  └────┘  │
  │/  SLEEVES \         │          │
  │            │         │          │
  │            │         │          │
  └────────────┘         └──────────┘

  - Cut off sleeves at the seam
  - Cut collar if needed for comfort
  - Tie or sew edges to prevent fraying
  - Use as insulation layer or light outer layer
```

## How to Repair Clothes

### The Basic Stitch

Learn one stitch and you can fix almost anything.

```
RUNNING STITCH
===============

  Thread the needle, tie a knot at the end.

  Step-by-step:

  1. Push needle up through fabric from back
  2. Push needle down through fabric from front
  3. Pull thread tight
  4. Repeat

  ─────Up─────Down─────Up─────Down─────
     │         │         │         │
     ▼         ▼         ▼         ▼

  The stitch looks like:
  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─

  TIP: Keep stitches same size for strong repair
  - Small stitches = strong but slow
  - Large stitches = weak but fast
  - Aim for medium (about 1/4 inch apart)
```

### Patching Holes

```
PATCH TECHNIQUE
===============

  1. Cut patch slightly larger than hole
  ┌─────────────┐
  │   ┌─────┐   │  ← patch
  │   │HOLE │   │  ← damage
  │   └─────┘   │
  └─────────────┘

  2. Place patch over hole, pin or hold

  3. Sew around edges (small, tight stitches)
  ┌─────────────┐
  │ ○○○○○○○○○○○ │  ← stitches around patch
  │ ○ ┌─────┐ ○ │
  │ ○ │ HOLE│ ○ │
  │ ○ └─────┘ ○ │
  │ ○○○○○○○○○○○ │
  └─────────────┘

  4. For big holes: sew in cross pattern first
  ┌─────────────┐
  │   ┌─────┐   │
  │   │  │  │   │
  │   ├──┼──┤   │  ← cross stitches hold edges
  │   │  │  │   │
  │   └─────┘   │
  └─────────────┘
```

### Reinforcing Stress Points

These spots tear first. Add extra stitching before they rip.

```
STRESS POINTS
=============

       ┌─────┐
      ╱│  ▲  │╲      ▲ = reinforce these spots:
     ╱ │  │  │ ╲
    ╱  │  │  │  ╲      • Underarms
   ╱   │  │  │   ╲     • Crotch
  ┌────┤  │  ├────┐    • Knee area
  │    │  │  │    │    • Elbow area
  │    │  │  │    │    • Waist seams
  │    │  │  │    │    • Pocket corners
  │    │  │  │    │
  │    │  │  │    │
  │    └──┘  └─── │
  │               │
  └───────────────┘

  Add 2-3 rows of stitching at stress points.
  Use double thread for extra strength.
```

## The Phi-Clothing System

The golden ratio (φ = 1.618) applies to clothing too. It's the ratio found in nature — in shells, flowers, and your own body. Use it to make clothes that fit better.

### Layer Thicknesses at Phi-Ratios

```
PHI-LAYER THICKNESSES
======================

  Layer 3 (Shell):   1 unit thick
  Layer 2 (Warmth):  1.618 units thick  (× φ)
  Layer 1 (Base):    2.618 units thick  (× φ²)

  Example in millimeters:

  ┌─────────────────────────────────────┐
  │ Layer 3: 0.5mm   (waterproof shell) │
  │ ═══════════════════════════════════  │
  │ Layer 2: 0.8mm   (wool fleece)      │
  │ ═══════════════════════════════════  │
  │         ═══════════════════════════  │
  │ Layer 1: 1.3mm   (cotton base)      │
  │ ═══════════════════════════════════  │
  └─────────────────────────────────────┘

  WHY THIS WORKS:
  - Thinnest layer outside (blocks wind/rain)
  - Thickest layer inside (absorbs sweat)
  - Middle layer bridges the gap
  - The phi-ratio creates natural comfort
```

### Garment Proportions

Use the golden ratio to size your clothes:

```
PHI-PROPORTIONS FOR CLOTHING
==============================

  If your waist = W

  Jacket length:  W × 1.618
  Sleeve length:  W × 0.618  (1/φ)
  Collar width:   W × 0.382  (1/φ²)

  Example (waist = 30 inches):

  Jacket:  30 × 1.618 = 48.5 inches
  Sleeve:  30 × 0.618 = 18.5 inches
  Collar:  30 × 0.382 = 11.5 inches

  THE PHI-SCARF
  ==============
  Cold weather:  50 inches (long)
  Mild weather:  31 inches (medium)
  Warm weather:  19 inches (short)

  Each length = previous × 0.618
  (50 × 0.618 = 31,  31 × 0.618 = 19)

  The scarf length adapts to temperature
  using the same ratio nature uses.
```

### Why Phi Works for Clothing

Your body already uses phi proportions:

- Your arm span ≈ your height × φ
- Your face width ÷ face height ≈ 1/φ
- Your finger bones follow phi ratios

Clothes made at these ratios feel natural because they match your body.

### Where to Find Free Materials

- **Old clothes** — cut into patches, use fabric for new items
- **Bedsheets** — large cloth source for ponchos, bags
- **Curtains** — big pieces of fabric
- **Thrift stores** — clothes for $1-2 to cut up
- **Fabric stores** — ask for scraps (often free)

## Quick Reference

| Situation | What to Wear | What to Make |
|-----------|-------------|--------------|
| **Hot sun** | Light layers, hat, long sleeves | Poncho for shade |
| **Cold** | 3+ layers, hat, gloves | Vest from shirt |
| **Rain** | Shell layer, waterproof hat | Tarp poncho |
| **Thorns/brush** | Long pants, long sleeves, shoes | Reinforce knees/elbows |
| **Fire work** | All natural fibers, no synthetics | Leather gloves |
| **Sleep** | Extra insulation layer | Blanket from joined cloths |

**Key Rule:** Clothes are tools. Treat them that way. Keep them clean, dry, and repaired. A small tear becomes a big tear if you ignore it. Fix problems when they're small.
