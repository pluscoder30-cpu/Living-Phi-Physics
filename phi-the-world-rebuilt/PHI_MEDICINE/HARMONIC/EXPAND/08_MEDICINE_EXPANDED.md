# SECTION 3: THE DOSE OPTIMIZATION ALGORITHM

## 3.1 Adaptive Dosing Principle

The dose optimization algorithm adjusts frequency amplitude based on patient response. The goal: maintain the optimal coherence accumulation rate without overshooting or undershooting.

**Core Equation:**
```
A_optimal = A_baseline × (C_measured / C_predicted) × correction_factor
```

## 3.2 Three Adjustment Rules

### Rule 1: Faster Than Predicted

**Condition:** C_measured > C_predicted × φ⁻¹ (coherence is accumulating faster than expected)

**Action:** Reduce frequency amplitude by φ⁻¹

```
A_new = A_old × φ⁻¹ = A_old × 0.618
```

**Rationale:** Coherence is accumulating too fast. If left unchecked, the patient may experience a coherence overshoot — similar to a Herxheimer reaction. Reducing amplitude slows the accumulation to the predicted rate.

**Example:**
```
Day 21: C_measured = 0.450, C_predicted = 0.430
Ratio: 0.450 / 0.430 = 1.047 > φ⁻¹ = 0.618 → Rule 1 applies
A_new = 0.223 × 0.618 = 0.138
Next session amplitude: 0.138 (reduced from 0.223)
```

### Rule 2: Slower Than Predicted

**Condition:** C_measured < C_predicted × φ⁻¹ (coherence is accumulating slower than expected)

**Action:** Increase frequency amplitude by φ

```
A_new = A_old × φ = A_old × 1.618
```

**Rationale:** The current amplitude is insufficient. The patient's coherence gap is larger than initially estimated, or external factors (stress, illness, poor compliance) are reducing the treatment effect. Increasing amplitude compensates.

**Safety Cap:** A_new must never exceed 0.500. If A_old × φ > 0.500, cap at 0.500.

**Example:**
```
Day 35: C_measured = 0.440, C_predicted = 0.480
Ratio: 0.440 / 0.480 = 0.917 < φ⁻¹ = 0.618 → NOT Rule 2
(Note: 0.917 > 0.618, so this is within normal variance — no adjustment needed)
```

