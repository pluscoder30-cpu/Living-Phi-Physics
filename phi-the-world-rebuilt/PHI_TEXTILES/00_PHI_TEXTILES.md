- φ = 1.6180339887

```

```

where:
- d_pore = pore diameter between threads

**The phi-breathability optimum occurs when:**

```

This is why layered fabrics work better than thick single fabrics — each layer is φ-thin, and the φ layers create exponential breathability decay for liquid while maintaining linear vapor transport.

```
