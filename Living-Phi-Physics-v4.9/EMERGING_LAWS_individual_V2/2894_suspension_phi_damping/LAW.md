# PHI Suspension Damping Optimization

**Domain**: Automotive Engineering

**Statement**:
Vehicle ride comfort maximized when damping ratio c = 2*sqrt(km)/phi, achieving comfort index CI = CI0*phi ≈ 1.618*CI0 vs critically damped.

**Derivation**:
Damped oscillator: c_cr = 2*sqrt(km). For comfort minimize acceleration. Phi-tuned: c = c_cr/phi. Response H(w) minimized at w = w_n/phi.

**Prediction**:
Phi-tuned damping gives 61.8% lower RMS seat acceleration vs critically damped vehicles.

**Test**:
Install phi-tuned vs critically damped suspensions. Drive standard profile. Measure RMS seat acceleration. Expect phi ≈ 0.618× critical.
