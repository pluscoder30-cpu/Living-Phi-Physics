## Key Patterns

1. **Dual jurisdiction** — Properties in one jurisdiction, entities in another (Florida property → USVI entity; New Mexico property → USVI entity)
2. **$0 transfers** — Properties passed between shell companies for $0 or $10, avoiding recording requirements
3. **Shared addresses** — Multiple entities at single addresses (575 Lexington = 39+ entities; 6100 Red Hook = 5 entities)
4. **Registered agent shield** — Delaware entities use CSC as nominee, creating anonymity layer
5. **Offshore registration** — Maximum secrecy jurisdictions (Bermuda, USVI) for the most sensitive entities
